# Safe driving norm orientation: analysis code

Analysis code for the manuscript *An Empirically Unified Safe Driving Norm Orientation: Psychometric
Evidence for Measurement Invariance Across Driving-Experience Groups*.

The study is a secondary analysis of an openly available survey of 1,039 Chinese urban drivers
(Jin et al., 2023; see [`data/README.md`](data/README.md)). Every table, figure and in-text statistic
in the Results section is regenerated by the scripts below, and `verify.py` checks the regenerated
values against those printed in the manuscript.

## Quick start

```bash
python -m venv .venv && source .venv/bin/activate      # Python 3.11 was used
pip install -r requirements.txt
# download the dataset into data/ (see data/README.md), then
python run_all.py
```

`run_all.py` runs the ten scripts in `analysis/` in order and then `verify.py`. The full pipeline takes
roughly 5–10 minutes on two CPU cores, almost all of it in the resampling study (script 07); every
other script finishes in under a minute. Results are written to `results/` (JSON and CSV) and figures
to `figures/`. No proprietary software is required.

## Implementation notes

All estimators are implemented directly in `sdn/` with NumPy and SciPy, so the estimation details are
fully visible:

* `sdn/cfa.py` – single-group ML CFA; χ² = (N − 1)F. The same routine is used for the full sample,
  for each experience group and for every resample, so all CFA fit statistics share one convention.
* `sdn/mgcfa.py` – multi-group CFA with a mean structure (configural, metric, scalar), analytic
  gradients, χ² = (N − 1)F.
* `sdn/irt.py` – Bock–Aitkin marginal ML (EM) for the GRM and GPCM on a 61-node grid over [−4, 4],
  optional empirical-histogram latent density, EAP scoring, infit/outfit, Yen's Q3, separation
  indices. The normal-density GRM converges in 261 EM cycles (−2LL = 62,431.0).
* `sdn/lca.py` – unrestricted latent class models by EM with random starts (seed 7).
* `sdn/stats_utils.py` – α, HTMT, AVE, Holm adjustment, two-step polychoric correlation.

Random elements use fixed seeds: the resampling study seeds each draw separately (so results do not
depend on the number of worker processes), the Gaussian mixtures use `random_state=0`, and the latent
class starts use `numpy.random.default_rng(7)`.
